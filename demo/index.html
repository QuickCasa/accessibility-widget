Accessibility Widget by QuickCasa GitHub

An accessibility toolbar that does not lie to you.

One script tag gives your visitors real control over contrast, text size, spacing, focus and motion, plus a skip link that actually moves focus. No API key, no backend, no tracking, about 6 KB gzipped. Free and open source under the MIT licence.

The round button in the bottom right corner is the real widget, running on this page. Press Tab once from the top to find the skip link.

What visitors get

  • Skip to main content

    A real first tab stop that moves keyboard focus, not just the scroll position.

  • Colour contrast

    A forced light-on-dark or dark-on-light palette that keeps sticky headers working.

  • Text size

    Four steps up to 150 percent, behaving like browser zoom so pixel-based sites scale too.

  • Text spacing

    The exact line, letter and word spacing from WCAG success criterion 1.4.12.

  • Underline links

    Underlines real links only, and leaves image and icon links alone.

  • Highlight focus

    A two-tone focus ring, so one of its colours is always visible on any background.

  • Reduce motion

    Collapses animations and pauses autoplaying video. Starts on when the operating system asks.

  • Remembered choices

    Saved on the visitor's device only. Nothing is ever sent anywhere.

What it does not do

This does not make your site WCAG or ADA compliant, and it does not reduce your legal exposure. No script can. Some overlay vendors have been sued and fined for claiming otherwise.

It does not generate alt text, rewrite your markup or attempt automated remediation. Accessibility comes from how a site is built and tested.

What it does is give visitors controls over their own experience, and add one genuine structural fix in the skip link. That is the whole claim.

Add it to your site

Download accessibility.js from the latest release, host it alongside your site, and add one tag to your <head>. Every attribute except src is optional. 

<script
  src="/accessibility.js"
  data-qc-accessibility
  data-position="bottom-right"
  data-accent="#5B1FE0"
  defer></script>

To try it before you host anything, point src at the copy on this site: https://quickcasa.github.io/accessibility-widget/v1/accessibility.js. It tracks the latest 1.x release.

Configuration

Everything is a data attribute on the script tag. Invalid values are ignored with a console warning.

Attribute Default Notes
data-main-content-selector automatic Where the skip link goes. Falls back to main, then [role="main"] and other common patterns.
data-position bottom-right Also bottom-left, top-right or top-left.
data-accent #6A24FF Hex only. Used for borders and focus rings, never behind text.
data-features all Comma-separated allowlist: skip-link, contrast, text-size, text-spacing, link-underline, focus-outline, reduce-motion.
data-button-label Accessibility options The accessible name of the trigger button.
data-storage-key qc_a11y_v1 The localStorage key, for keeping several sites on one origin apart.

Test pages

  • Stress test: a fixed header, a background-image hero, pixel-sized text, a looping animation and an image-only link.
  • Hostile configuration: no main element and deliberately invalid attributes, including an attempt to inject CSS.
  • Strict Content-Security-Policy: no inline styles, no inline scripts, no network requests and Trusted Types enforced.
